# Reassurance recording

Original text from `src/dialogue.json`, synthesized locally with Windows
System.Speech, Microsoft Mark (male, en-US), rate -1. No actor voice cloning.
The WAV is mono, 24 kHz, signed 16-bit PCM, duration 4.812917 seconds.
Only the WEM is packed into the game archive. Both Reed reassurance branches
and both player gender VO paths reference the same recording.

Generated by `tools/generate_voice.ps1`. The converter is
[wav2wem v0.1](https://github.com/pas2k/wav2wem/releases/tag/v0.1), kept locally
under `.tools/` and not distributed with this mod. Downloaded executable SHA256:
`5a10738a73d5451ede6a526a7aa0bfe7f42b41faffe78c9b62ec9f223f91d736`.
It produces Wwise Vorbis using aoTuV 6.03 codebooks.

Other rewritten lines remain subtitle-only. In-game playback and mixing require
a replay from before the scene; successful conversion alone is not proof of playback.
